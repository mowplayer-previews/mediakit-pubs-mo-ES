# MOW Player · Publishers

Presentación para publishers (6 slides) en HTML estático.

- Abrí `index.html` en el navegador, o publicalo con GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
- Navegación: flechas ← →, espacio, clic o swipe. `F` pantalla completa, `N` notas del orador.
- Las animaciones son GIFs en `assets/`.
